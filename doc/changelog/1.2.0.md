# 1.2.0

* Fix `CycleDetector.Undirected` reporting false-positive cycles
* Fix `Distinct` and `DistinctEndo` composition order and associativity
* Fix `Eval.{allPresent,whitelist,blacklist}` exhausting iterators before formatting failure reports
* Fix `Gen.batches` to reject invalid args and potentially generate trailing empty vectors
* Fix `Gen.frequency` omitting or under-weighting the last element
* Fix `Gen.negativeInt` and `Gen.negativeLong` to allow `MinValue`
* Fix `Gen.positiveInt` and `Gen.positiveLong` yielding negative values for `MinValue`
* Fix `Gen#subset1` evaluating generator twice and mixing samples
* Fix `GenCtx.nextBit` repeating bit 0 on every 33rd call
* Fix `Logic.unary_~` not negating the name of `Named` properties
* Fix `SetLike.byClassTag` failing to resolve `ByClassTag` instances
* Fix string escaping of backslashes in test failure reports
* Fix typo in `Gen.chooseInt` invalid range exception message
* Optimise `CycleDetector.Directed` from exponential to linear time

  * Monocle -> 3.3.0
